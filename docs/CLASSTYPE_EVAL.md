## Methodology

1. For each TTB ID with label images, run Tesseract.js OCR on all images
2. Extract classType, varietal, and ageStatement from OCR text using regex patterns
3. Run inferCategory() with extracted fields to map to official TTB class/type codes
4. Compare inferred subcategory against ground truth classType from TTB COLA records
5. Score as exact match (normalized), family match, or mismatch
